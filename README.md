# SQL Business Performance Analysis

## Executive Summary

This project uses SQL and relational database analysis to evaluate business performance across 13 interconnected tables.

The analysis focused on identifying revenue concentration, differences in agent performance, and opportunities to improve business performance through data-driven decision making.

## Business Questions

The project explored questions such as:

* Which products, customers, or agents contribute the most revenue?
* How concentrated is revenue across the organization?
* Are there meaningful differences in performance across agents?
* What business opportunities can be identified from transaction-level data?

## Dataset

The project used a relational database consisting of **13 interconnected tables** containing business, customer, transaction, and performance information.

## Methodology

The analysis included:

1. Understanding the relational database structure
2. Joining data across multiple tables
3. Cleaning and validating records
4. Aggregating revenue and performance metrics
5. Identifying patterns and performance differences
6. Translating the results into business recommendations

## Key Findings

One key finding was that **4 of 9 agents generated approximately 66% of total revenue**, indicating meaningful revenue concentration across the organization.

Additional findings and visualizations will be added as this repository is developed.
